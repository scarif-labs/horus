# Terminal emulator dependencies

Horus uses `@xterm/headless` 6.0.0 and `@xterm/addon-unicode11` 0.9.0
from [xterm.js](https://github.com/xtermjs/xterm.js). Versions and integrity
hashes are pinned in `package-lock.json`. The headless core supplies VT parsing
and cell buffers; the Unicode addon supplies character widths. The React Native
cell renderer is part of Horus.

# Terminal symbol font

The native terminal renderer bundles `android/app/src/main/assets/fonts/TerminalSymbols.ttf`,
a subset of [Noto Sans Symbols 2](https://github.com/notofonts/symbols)
(arrows, miscellaneous technical, geometric shapes, miscellaneous symbols,
dingbats, and miscellaneous symbols and arrows; emoji-presentation characters
removed) used as a fallback after Fira Code. It is licensed under the SIL Open
Font License, Version 1.1; the full license text ships next to the font as
`android/app/src/main/assets/fonts/NotoSansSymbols2-OFL.txt`.


# PRoot runtime

`native/` holds the sources of the PRoot runtime, which the Gradle build
compiles into `libproot.so` and `libproot_loader.so` (see
`scripts/native/build-proot-runtime.sh`). They are separate programs under
their own licenses:

- **PRoot** 5.1.107.92: GNU General Public License v2.0 or later (GPL-2.0-or-later).
  Source: `native/proot` (git submodule of <https://github.com/termux/proot>),
  modified by `native/patches/proot-android.patch`.
- **talloc** 2.4.3: GNU Lesser General Public License v3.0 or later, see
  `native/talloc/LICENSE`. Source: `native/talloc`, taken from
  <https://www.samba.org/ftp/talloc/talloc-2.4.3.tar.gz>; `config.h` was
  generated by its `configure` script for Android.
- **libandroid-shmem** 0.7: BSD 3-Clause License.
  Source: `native/libandroid-shmem` (git submodule of
  <https://github.com/termux/libandroid-shmem>).

talloc and libandroid-shmem are linked statically into PRoot. The MIT license
of this repository does not apply to these components.
