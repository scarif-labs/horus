<p>Your phone is an ARM64 Linux computer that spends most of its day running chat apps. Horus gives it a real job: it unpacks Alpine Linux inside the app and opens a terminal where <b>Claude Code</b>, <b>Codex</b>, and <b>OpenCode</b> can read your code, edit files, run the tests, and tell you what broke. You don't need root, Termux, or a computer.</p>

<p>Ask an agent to fix a failing test while you're on the bus, then put the phone away. Sessions run in a foreground service, so they keep working with the screen off, and Horus sends a notification when an agent finishes or needs an answer from you.</p>

<p><b>What you get</b></p>
<ul>
<li><b>Coding agents in one tap.</b> Pick an agent and Horus installs it the first time you open it, with the installer output right there in the terminal. You sign in inside each CLI; Horus never sees your provider credentials.</li>
<li><b>A real Linux shell.</b> Alpine comes from a pinned minirootfs whose SHA-256 digest is checked before anything is unpacked, and git, curl, ripgrep, Python, and Node are installed on demand. npm test, pytest, and a static ffmpeg build all run the way they would on a server.</li>
<li><b>A terminal you can use with your thumbs.</b> Swipe typing works, links open with a tap, and a key bar above the keyboard adds Esc, Tab, arrows, paste, and one-shot Ctrl and Alt.</li>
<li><b>Your projects.</b> Create a folder, clone any HTTPS or SSH Git URL, or sign in to GitHub and pick one of your repositories.</li>
<li><b>Up to four sessions at once</b>, say Claude Code in one project and Codex in another, each with its own notification.</li>
<li><b>A file browser</b> for checking what the agents changed, with text previews and a button that copies any folder to your Downloads.</li>
<li><b>A lock.</b> An optional password protects the app, and the workspace locks itself after 15 minutes in the background.</li>
<li><b>Optional USB access from a computer.</b> Pair the open-source horus command-line tool to get an SSH shell on the phone, copy files, forward ports, or run one command on several phones. It's off by default, listens only on the phone's loopback (reached through adb), and accepts only computers paired with your Horus password.</li>
</ul>

<p><b>Things to know</b></p>
<ul>
<li>Horus needs an ARM64 (arm64-v8a) phone running Android 7.0 or newer.</li>
<li>Alpine, its packages, and the agents download from their upstream servers when you first use them; mirrors are available in Settings for networks that can't reach those servers. Claude Code and Codex need accounts with their providers. Claude Code is proprietary, while Codex (Apache-2.0), OpenCode, and the shell are free software.</li>
<li>Android's app sandbox is the only security boundary. PRoot emulates user IDs but gives no kernel isolation, so don't run code you don't trust.</li>
</ul>
